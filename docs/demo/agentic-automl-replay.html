Claude Code does the ML

Claude profiles the data, plans, and writes and runs every script. It works from tested step scripts copied into templates/, adapting them instead of writing from scratch.

The checker owns the state

agentic-automl artifacts validates each step's output against a JSON schema plus consistency checks, enforces the step order, and is the only writer of state/. It never trains anything.

Hooks are the guard rails

PreToolUse hooks reject direct writes to saved outputs, and permission rules auto-approve the safe commands (Bash and PowerShell). Failures are recorded as feedback for improving the platform.

Technical skills on show

Agent engineering

  • Claude Code skills (one SKILL.md per step), runtime instructions in CLAUDE.md
  • PreToolUse hooks, permission allow-lists, trust mode
  • Headless runs (claude -p) with budget, turn and tool caps, plus stream-json recording
  • Windows support: PowerShell tool, Git Bash for hooks, path limits, byte-order marks

Platform engineering

  • Python package with a CLI (uv tool): new, resume, fork, status, config, update
  • JSON Schema draft-07 for every step output, with ordered checks and redirects
  • Eval harness with free and Claude tiers, scenario answer banks, TSV reports
  • 299 pytest tests, including the step scripts run end to end

Machine learning

  • Leakage probes: out-of-fold single-feature AUC, too-good-to-be-true checks
  • Validation folds matched to the problem: time-ordered, grouped, stratified
  • Feature selection: Spearman, IV/WoE, mutual information, VIF, L1, permutation importance
  • Vintage analysis: p-chart, maturity, PSI, window backtest
  • Paired per-fold model choice, thresholds from validation, bootstrap CIs
